# Bank Transaction Fraud Detection System

## Description
This project detects fraudulent bank transactions using Machine Learning.

##  Features
- Uses 6 Machine Learning algorithms
- Random Forest gives best accuracy
- Hyperparameter tuning applied
- Streamlit web application

##  Accuracy
Around 90% accuracy

##  Files Included
- app.py → Streamlit app
- fraud_detection.ipynb → Model training
- requirements.txt → Required libraries

##  Note
Model file (fraud_model.pkl) is not uploaded due to size limitation.

## ▶ How to Run
1. Install libraries:
   pip install -r requirements.txt

2. Run app:
   streamlit run app.py
